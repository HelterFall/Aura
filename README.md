# Aura

Aura — Android-приложение для исследования и извлечения ресурсов из архивов визуальных новелл.

Первый реализованный контейнер — Nitro+ PAK v2/v3. Каждый следующий формат будет отдельным обработчиком.

## Текущий статус

- [x] Android-проект на Kotlin + Jetpack Compose.
- [x] Выбор игровой папки через Storage Access Framework.
- [x] Просмотр файлов и каталогов первого уровня.
- [x] Предварительное определение кандидатов на архив по расширению.
- [x] Чтение индекса Nitro+ PAK v2.
- [x] Чтение индекса Nitro+ PAK v3.
- [x] Потоковое извлечение PAK с zlib-декомпрессией и XOR-префиксом v3.
- [x] Проверка размеров, смещений и путей при извлечении.
- [x] Unit-тесты на синтетических архивах v2/v3.
- [x] GitHub Actions для сборки debug APK и загрузки артефакта.
- [ ] Извлечение NPA.
- [ ] NPK2 с поддержкой выбранных схем шифрования.
- [ ] Просмотр и преобразование игровых изображений и аудио.
- [ ] KiriKiri/XP3 и другие движки.

Важно: .pak используется многими движками. Сейчас Aura открывает только Nitro+ PAK v2 и v3; другие разновидности будут отклонены при проверке заголовка.

## Использование PAK

1. Выбери папку с файлами игры.
2. Открой файл с расширением .pak.
3. Проверь список файлов, который Aura прочитала из индекса.
4. Нажми «Извлечь всё» и выбери папку назначения.
5. Результат появится в отдельной папке с суффиксом _extracted.

Файлы извлекаются в исходном виде, без преобразования изображений и звука. Абсолютные пути и записи с .. не извлекаются. При совпадении имён добавляется числовой суффикс.

## Сборка

Требования: JDK 17, Android SDK Platform 35, Gradle 8.9.

~~~bash
gradle :app:testDebugUnitTest
gradle :app:assembleDebug
~~~

APK: app/build/outputs/apk/debug/app-debug.apk.

## GitHub Actions

Workflow .github/workflows/android-apk.yml запускается при push в main, pull request и вручную. После успешной сборки скачай артефакт Aura-debug-apk со страницы запуска Actions. Это debug APK для тестирования, не release-сборка для Google Play.

## Архитектура

- app — Android UI и Storage Access Framework.
- core/archive — случайный доступ к данным, модели записей и безопасное извлечение.
- NitroPakReader.kt — чтение Nitro+ PAK v2/v3.
- formats — будущие независимые обработчики контейнеров.
- codecs — будущие декодеры изображений и аудио.
